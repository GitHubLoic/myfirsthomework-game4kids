# Univers dinosaures

Illustrations vectorielles créées pour cette adaptation, servies localement :

- `volcano.svg` : volcan endormi et son petit terrain, utilisé sur l’accueil, la carte, les réponses et le trésor.
- `jungle.svg` : paysage préhistorique, végétation et sentier.
- `egg.svg` : œuf tacheté pour les activités de dénombrement et les collections.

Le personnage est le SVG `dinoSVG` dans `js/boat.js`. Sa couleur est personnalisable dans le coin des parents. Les pattes sont animées pendant les déplacements et respectent la préférence de réduction des animations.

Les nombres, lettres, aides et autres contrôles restent en HTML, séparés des illustrations. Aucun service externe n’est nécessaire au chargement de ce thème.
